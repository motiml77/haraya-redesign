# חיפוש במסמכי וורד בעברית

תוכנת שולחן עבודה לחיפוש מהיר וגמיש בתוך מסמכי וורד (‎.docx‎) בעברית.

* **סל חיפוש** – בוחרים תיקיות שלמות (כולל תתי־תיקיות) או מסמכים בודדים; אפשר להחזיק כמה סלים
  בשמות שונים ולעבור ביניהם. אפשר גם לגרור קבצים ותיקיות מהסייר.
* **חיפוש שמתעלם מניקוד, טעמים, גרשיים וסימני פיסוק** – `בְּרֵאשִׁית` = `בראשית`, `רש"י` = `רש״י` = `רשי`.
* **גמישות:**
  * אותיות שימוש – `דרך` ימצא גם `בדרך`, `והדרך`, `כשבדרך`.
  * הטיות – `הלך` ימצא `הלכה`, `הליכה`, `הולכים`, `ההולך`, `וילך`, `ללכת`.
  * אותיות אהו״י – כתיב מלא/חסר (`שמרה` ↔ `שמירה` ↔ `שומרה`), או גמישות בכל אותיות אהו״י.
  * רווח בין מילים – צמודות, עד N מילים ביניהן, או בכל מקום באותה פסקה; עם או בלי שמירה על הסדר.
  * תחביר: `הלכ*` (כל המשך), `מש?` (אות אחת), `משה|אהרן` (או), `שבת -חול` (בלי).
* **תוצאות** – מקובצות לפי מסמך, עם עמוד ומספר פסקה (או מספר הערת שוליים), וקטע של 40 מילים:
  20 לפני מילות החיפוש ו־20 אחריהן, כשהמילים שנמצאו מודגשות. מעל התוצאות מופיעות כל
  הצורות שנמצאו (למשל `הלכה (45) · הליכה (12)`) ולחיצה על צורה מסננת לפיה.
* **לחיצה על תוצאה פותחת את המסמך.** בחלונות עם וורד מותקן המסמך נפתח בוורד והמילים
  שנמצאו מסומנות במקומן המדויק. במערכות אחרות המסמך נפתח והטקסט מועתק ללוח (Ctrl+F, Ctrl+V).

## התקנה והפעלה

### חלונות
1. התקינו [Python](https://www.python.org/downloads/) 3.9 ומעלה (סמנו "Add python.exe to PATH").
2. לחיצה כפולה על `run.bat` – בפעם הראשונה הוא מתקין את מה שצריך, ואחר כך פשוט פותח את התוכנה.

ליצירת תוכנה עצמאית (`exe`) שאפשר להעתיק למחשב אחר בלי פייתון: לחיצה כפולה על `build_exe.bat`.
התוצאה בתיקייה `dist\HebWordSearch`.

### מק / לינוקס
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

### שורת פקודה (בלי ממשק)
```bash
python -m hebsearch.cli search "הלך בדרך" "C:\מסמכים" --inflections --gap 2
python -m hebsearch.cli index "C:\מסמכים"
```

## איך עובדת "מפת החיפוש"

סריקה של כל המסמכים בכל חיפוש איטית מדי (צריך לפתוח כל קובץ, לפרק XML ולנרמל כל מילה),
ובוודאי כשכל מילת חיפוש הופכת לעשרות צורות. לכן כל מסמך נקרא **פעם אחת** ונבנה ממנו אינדקס
הפוך (כמו מפתח בסוף ספר) שנשמר במסד נתונים SQLite בתיקיית הנתונים של המשתמש:

| טבלה | תוכן |
|---|---|
| `vocab` | אוצר המילים: כל מילה מנורמלת שהופיעה אי־פעם, עם מזהה מספרי |
| `postings` | לכל (מילה, מסמך): רשימת כל המופעים – זוגות (מספר פסקה, מיקום המילה בפסקה) |
| `texts` | הטקסט המקורי של המסמך (דחוס), עם עמוד וסוג לכל פסקה – רק לבניית קטעי התצוגה |
| `files` | נתיב, זמן שינוי וגודל – כדי לקרוא מחדש רק מסמכים שהשתנו |

**נרמול** – לפני שמילה נכנסת למפה (וגם כל מילת חיפוש) מסירים ממנה ניקוד, טעמים, גרשיים
ומירכאות, ומחליפים אותיות סופיות ברגילות (`הלך` → `הלכ`), כך שהשוואה היא השוואת מחרוזות פשוטה.

**חיפוש בשלושה שלבים:**
1. **התאמה על אוצר המילים, לא על הטקסט.** כל מילת חיפוש הופכת לתבנית (ביטוי רגולרי) שמתארת
   את כל הצורות המותרות – תחיליות, סיומות, אמות קריאה, אהו״י, תווים כלליים. התבנית רצה על רשימת
   המילים הייחודיות (עשרות אלפים) ולא על הטקסט (מיליוני מילים), ולכן גם חיפוש רחב מאוד מהיר.
2. **שליפה וחיתוך.** לכל צורה שנמצאה נשלפים המופעים שלה מהמפה – רק במסמכים שבסל.
   מתחילים מהמילה הנדירה ביותר, וכל מילה נוספת נבדקת רק בפסקאות שעדיין רלוונטיות.
3. **בדיקת מרחק וסדר על המיקומים בלבד.** כיוון שהמפה שומרת את מיקום כל מילה בפסקה,
   "עד 3 מילים ביניהן" או "לפי הסדר" נבדקים בחישוב על מספרים – בלי לקרוא טקסט בכלל.

את הטקסט עצמו קוראים רק כדי לבנות את קטעי ה־40 מילים, ורק לתוצאות שעל המסך (100 בכל פעם).

**מספרים** (מדידה על 800 מסמכים, כ־4 מיליון מילים): בניית המפה בפעם הראשונה – כ־15 שניות;
בדיקה שלא השתנה דבר – עשירית שנייה; חיפוש מילה עם הטיות (11,700 תוצאות) – כ־0.1 שנייה;
צירוף עם מרחק – כ־0.01 שנייה.

**עדכון** – בכל חיפוש התוכנה בודקת (לפי תאריך שינוי וגודל) אם נוספו או השתנו מסמכים בסל,
וקוראת מחדש רק אותם. מסמכים נקראים במקביל בכמה ליבות מעבד.

## על "שורה", עמוד ופסקה

קובץ וורד לא שומר שורות – חלוקת הטקסט לשורות מחושבת מחדש בכל פעם לפי הגופן, השוליים
והמדפסת. לכן כל תוצאה מציגה:
* **עמוד** – לפי חלוקת העמודים שוורד שמר בקובץ בפעם האחרונה שהמסמך נשמר בוורד
  (זה המספר שרואים בוורד; במסמכים שלא נשמרו בוורד נספרות רק שבירות עמוד מפורשות),
* **מספר פסקה** בגוף המסמך, או **מספר הערת שוליים / הערת סיום**.

ובחלונות עם וורד, לחיצה על התוצאה פותחת את המסמך ו**מסמנת בדיוק את המילים שנמצאו**,
כך שמגיעים ישר לשורה הנכונה.

## מגבלות
* **הטיות** הן קירוב היוריסטי (לא מילון מורפולוגי): הן עשויות להחמיץ צורות חריגות (למשל
  `בית` ↔ `בתים`) או למצוא מילה ששורשה אחר אך אותיותיה דומות. רשימת "צורות שנמצאו" מאפשרת
  לראות מה נכלל ולסנן.
* קבצי **‎.doc‎ ישנים** נקראים רק בחלונות עם וורד מותקן (דרך וורד עצמו, ולאט יותר). אחרת הם
  מסומנים "לא נקראו" – אפשר לשמור אותם מחדש כ־docx.
* כותרות עליונות ותחתונות לא נכללות בחיפוש; גוף המסמך, טבלאות, תיבות טקסט, הערות שוליים
  והערות סיום – כן.

## מבנה הקוד
```
main.py                   נקודת כניסה
hebsearch/normalize.py    נרמול עברית ופירוק למילים
hebsearch/morphology.py   בניית תבנית לכל מילת חיפוש (תחיליות, הטיות, אהו״י)
hebsearch/extract.py      קריאת docx (כולל עמודים והערות שוליים)
hebsearch/index.py        מפת החיפוש (SQLite) וסלים
hebsearch/search.py       מנוע החיפוש וקטעי התצוגה
hebsearch/opener.py       פתיחת המסמך במקום (וורד בחלונות)
hebsearch/cli.py          שורת פקודה
hebsearch/gui/            הממשק הגרפי (PySide6)
tests/                    בדיקות: python -m unittest discover -s tests
```
